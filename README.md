## Preview locally

From the repo root:

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

## Deploy (v1)

Connect this GitHub repo to [Vercel](https://vercel.com), [Netlify](https://netlify.com), or GitHub Pages. Framework preset: none. Publish directory: `.` (repo root). Redeploys on push.

GitHub Pages: Settings → Pages → Deploy from branch `main` / root.
