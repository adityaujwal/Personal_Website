Oncology data pipeline

Scale 10M+ cells Oncology clinical-trial data
Spec 6 tables Matched reference outputs exactly
Models Cox PH LASSO survival models in Python

Problem

Oncology analysis only works if records from different tables actually refer to the same cells and patients, and if the transformed outputs match a known spec. The data was clinical-trial scale — high-dimensional, split across sources, and large enough that silent join errors would poison anything downstream.

Approach

As an undergraduate AI developer in Purdue’s Data Mine partnership with Johnson & Johnson, I built a spec-driven pipeline for oncology clinical-trial data. The pipeline had to match reference outputs exactly across six tables and more than 10 million cells. I worked with statisticians to validate the assumptions behind those matches — not just key equality.

On the cleaned set I modeled patient outcomes across treatment regimens using Cox proportional hazards and LASSO survival models in Python, and presented the results to clinical stakeholders.

Result

Exact match to reference outputs across six tables at 10M+ cells. Downstream modeling of treatment outcomes sat on that spec rather than stalling in wrangling. Patient data and research internals stay off this site.
