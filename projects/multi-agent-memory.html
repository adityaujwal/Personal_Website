Problem

LLM agents that only pass messages forget what the rest of the team already learned. Work gets duplicated, contradictions sit unnoticed, and the final brief is whatever happened to be in the last thread.

Approach

I built a LangGraph demo in which a Coordinator routes Researcher, Analyst, and Critic agents on research tasks. They do not only chat. They read and write a shared workspace (findings, hypotheses, contradictions, decisions) so later steps can reuse prior work, flag conflicts, and consolidate into a brief.

Memory is an Endee-backed SharedMemoryManager, with a NullMemoryManager for isolated benchmarks. The Coordinator can preempt to the Critic when the workspace shows contradictions. A mock LLM path runs the demo without a live model. A Streamlit panel shows workspace timelines. Benchmarks and threshold-tuning scripts sit next to a blog post and a demo notebook.

Result

Phases 1–6 are largely done: memory wiring, a live graph, benchmarks, and the write-up/demo. Two caveats I would mention in an interview: the cold-start Endee wipe was not fully validated, and duplicate-work metrics are not meaningful under the mock LLM.
