Multi-agent shared-memory architecture

Shared memory Agents read and write a common store
Vector DB Retrieval instead of isolated chat history

Problem

LLM agents that only see their own thread forget what the rest of the system already learned. Work gets duplicated, decisions drift, and later agents cannot retrieve earlier findings.

Approach

I designed a shared-memory layer for a multi-agent setup, backed by a vector database. Agents write findings, decisions, and context into a common store and retrieve relevant pieces later, instead of passing the entire history through prompts or operating in isolation.

Result

A working architecture for shared agent memory via vector retrieval. This page is a write-up only until a public repo is confirmed.
